
# 📊 CSV Data Analysis & Visualization Dashboard

An interactive web application built with **Python**, **Streamlit**, **Pandas**, and **Plotly** that enables users to upload CSV files, explore datasets, perform statistical analysis, and generate interactive visualizations—all through an intuitive web interface.

## 🚀 Live Demo

**🔗 Live Application:**  
https://python-web-app--KumarPralhadd.replit.app

---

## 📌 Features

- Upload and analyze CSV datasets.
- Automatic detection of numerical and categorical columns.
- Interactive data filtering using sidebar controls.
- Descriptive statistical analysis including:
  - Mean
  - Median
  - Mode
  - Standard Deviation
  - Minimum & Maximum
  - Missing Value Analysis
- Interactive visualizations:
  - Histogram
  - Bar Chart
  - Scatter Plot
  - Line Chart
  - Box Plot
  - Correlation Heatmap
- Dataset preview and column information.
- Missing value analysis with visual reports.
- Download filtered datasets as CSV.
- Export summary statistics.
- Supports multiple CSV encodings:
  - UTF-8
  - Latin-1
  - ISO-8859-1
  - CP1252

## 🎯 Purpose

This project was developed to simplify exploratory data analysis by providing an easy-to-use dashboard where users can upload datasets, analyze trends, identify patterns, visualize relationships, and export results without writing code.
